## Methodology

1. The exact 18 routing IDs were taken from the authenticated preflight artifact. No marketing alias, parameter size, quantization, or hardware mapping was inferred.
2. Each non-empty final assistant message was reviewed against the supplied six-part rubric: Correctness, Instruction Following, Completeness, Clarity, Practical Usefulness, and Reasoning and Judgment, each scored 1–5. The response-level ledger below contains all 176 scored finals.
3. Scoring used repeatable prompt-specific requirement checks, structural section checks, constraint checks, and reviewer-calibrated penalties. For Tests 1–3, the largest language-matched Python fence was syntax-parsed; generated programs were not executed. Truncation, forbidden instructions, unsupported marketing claims, or named-model violations reduced the applicable dimensions.
4. Empty or error finals were not assigned prose-quality scores. They reduced only accepted count and reliability. A model's quality average therefore says nothing by itself about whether all ten requests returned an answer.
5. Final accepted usage comes from `ok=true` pane usage. Retry-inclusive usage comes from all Watchdog rows linked by chat session and pane correlation ID. Because 26 Watchdog rows store `total_tokens=0` while still containing input and output counts, retry-inclusive totals are derived as input plus output.
6. Cost is shown only for model IDs with a documented selected-model catalog rate in the preserved pricing snapshot. The eight generic `watchdog-fallback-estimate:v1` rows are labeled unavailable for cost comparison; their persisted fallback dollar fields are not treated as verified model rates. No OpenRouter price was used.

Rubric interpretation: 1 = unusable/major failure, 2 = major revision required, 3 = reasonable/useful starting point, 4 = strong/minor revision, 5 = correct, comprehensive, clear, immediately usable, or excellent for the named dimension. A total is the sum of the six dimension scores; there is no separate penalty for model availability.
