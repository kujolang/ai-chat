## Research method and conflict resolution

- Read local implementation before OpenAI research: bootstrap, auth middleware, schema/crypto/profile functions, bridge, native exec and native stream branch, journal, tool/action runtime, browser client auth and state/model paths. Architecture references are pinned to baseline `2209a410dc26c6576882b02030d0def29d964d93`.
- Used official OpenAI docs/help/discovery first, then public project source and Amp's own docs. Secondary search hits were discovery leads only and do not support availability decisions.
- S1's fetched body establishes today's announcement; cached search results initially stopped at September 25. Do not make a historical claim from the stale snapshot.
- S3/S18 commercial trial language does not contradict S2/S4/S5 OSS access. Paid/hosted service access remains gated; a user-run OSS VM has the narrow S9 procedure.
- Identity's all-user availability is distinct from S17's Plus/Pro inference eligibility. Native Codex's broader eligibility is another product/credential path.
- Discovery omits direct inference scopes, while S5 explicitly documents them. Record both; specialized documentation supplies the route contract. No live grant was requested to resolve per-account rollout.
- SIWC docs use example model names; AI Chat must discover available models rather than hardcode examples or assume the existing Codex fallback remains eligible.
- OpenClaw's listed integration and inspected older auth modules do not prove those modules are the new public route. Follow S5/S7/S12; no private ChatGPT API requests, browser tokens or cookies were used.
- Targeted searches for Devin/Warp and the other named partners did not yield a reusable public partner integration contract. Their official directory entries are affirmative participation evidence only. Vercel/Supabase/GitLab sign-in pages are not evidence that any developer can obtain their provisioned client access.
- No official numeric quota API or plan-name contract was established for direct SIWC tokens. Native App Server account metadata cannot be substituted for it.
